## Response format
Respond with a JSON object:
```json
{
  "summary": "one-line description of the approach",
  "steps": [
    {"action": "modify", "target": "SymbolName", "file": "path/to/file.go", "task": "what to change"},
    {"action": "create", "file": "path/to/new.go", "task": "what this file should contain"},
    {"action": "add", "target": "NewFuncName", "file": "path/to/file.go", "after": "ExistingFunc", "task": "what the new function does"},
    {"action": "run", "command": "go test ./...", "task": "verify changes"}
  ]
}
```
Use only symbols and files that exist in the repository structure above, unless the action is 'create' or 'add'. Be specific about what each step should accomplish.
